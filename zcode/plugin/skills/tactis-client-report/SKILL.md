# Tactis — отчёт для решения клиента

For an existing report, use [saved results](../tactis/references/saved-results.md) and return that exact original. For a requested new document, reuse the known recipient, purpose, period and relevant saved evidence. Use [entry](../tactis/references/session-entry.md) only for missing context; prepare the useful private deliverable while a delivery choice remains open.

## Shape the report around the decision

Choose the structure for the client's decision: continue, correct a problem, approve a next step or review a completed change. Use [the decision-report method](../tactis/references/marketing-review.md#report-for-a-decision) when its narrative guidance is needed. Show the supported result/comparison, interpretation and alternatives, material uncertainty, proposed action and its check.

Keep period, event meaning, attribution, currency/VAT, coverage and maturity with the relevant numbers. Use owner-backed values and supplied branding. Distinguish preparation, actual application and observation; a before/after result does not establish causality. Formatting a saved result does not require a new audit.

## Produce the requested deliverable

- For fixed Analysis HTML/PDF, read [private report mechanics](../tactis/references/mvp-workflow.md#frozen-measurements-and-private-reports). The renderer owns the numeric snapshot and template; supply grounded narrative and branding. Launch/experiment subjects retain their actual Application/measurement/outcome requirements.
- For a cross-source result, use [the matrix procedure](../tactis/references/marketing-data-matrix.md), reusing its manifest and needed rows. A matrix-only or CRM-only document uses an [authored HTML material](../tactis/references/platform-workflow.md#1-universal-creative-library-and-real-files), with its own source limits.
- For a public link or revocation, use [publication mechanics](../tactis/references/mvp-workflow.md#publish-a-saved-html-report). Preserve the selected access policy, exact version and actual active/revoked readback. Resolve a lost response under the same command identity.

Missing evidence leaves an explicit partial review or a concrete prerequisite, not invented numbers or report references. Return the actual artifact or verified link, covered period and applicable access condition. Creating or publishing a report does not send it to the client. Save a distinct finding or continuation through [the save stage](../tactis/references/durable-continuation.md#save-the-result-and-next-step); reuse an already suitable saved basis.
