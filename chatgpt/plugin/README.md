# Tactis Ads для ChatGPT Work

Восемь навыков Tactis помогают готовить рекламные тексты, разбирать рекламу и измерение, проверять страницы и сохранять результаты работы с бизнесом. Этот переносимый пакет содержит `plugin.json`, `mcp.json`, `skills/`, `assets/` и `release.json` непосредственно в корне ZIP. MCP называется `tactis_ads`, плагин — `tactis`.

## ZIP и публикация

Архив `tactis-ads-chatgpt-v<версия>.zip` из [официального выпуска Tactis](https://github.com/VasiliyR/tactis-plugins/releases) подготовлен для проверки и подачи через OpenAI Platform Plugins. Публикация в GitHub не означает одобрения или появления в публичном каталоге ChatGPT. Для каталога нужны проверенная организация разработчика, загрузка ZIP, подключение MCP, проверка домена и OAuth, материалы для review, одобрение и отдельная публикация.

В `mcp.json` заявлены streamable HTTP и OAuth DCR. Настройки OpenAI находятся в `extensions.com.openai`; фиксированных заголовков, токенов, client secret, lifecycle hooks и `.app.json` в архиве нет. Базовая JSON Schema MCP Agent Plugins 1.0.0 пока не описывает документированное расширение OpenAI `extensions.com.openai.auth`; проверяются переносимая часть и настройки OpenAI отдельно.

## Личное подключение в ChatGPT Work

1. В [ChatGPT Plugins](https://chatgpt.com/plugins) открой `+` → Add custom MCP server. Укажи название Tactis Ads, точный URL `tactis_ads` из `mcp.json`, включая весь путь после `/mcp/cloud/`, и OAuth. Заверши создание личного подключения штатным интерфейсом. Если эта возможность недоступна, проверь разрешения своего аккаунта или рабочего пространства.
2. Выполни вход в Tactis в браузере и подтверди показанный аккаунт и права. В Personal установи созданный плагин. Открой новый чат Work и через `@` выбери Tactis Ads.
3. Для добавления всех восьми навыков используй Plugin Creator и файлы из `skills/`, связав их с уже зарегистрированным MCP. Нужен настоящий app ID созданного подключения. `.app.json` с этим ID относится к отдельной личной сборке; он не подставляется в публичный ZIP и не создаётся из вымышленного значения. До завершения этого шага подключение MCP не равно установленному пакету с навыками.
4. Проверь, что доступны все навыки из `methodology.json.skills`. Вызови `get_plugin_update_status`, `list_projects` и затем `get_project_brief` для выбранного проекта. Сверь версии с `release.json`; результат `current` относится к заявленной версии подключения и сам по себе не доказывает, что ChatGPT загрузил файлы навыков без изменений.

Прямая загрузка этого submission ZIP как полного личного cloud-плагина здесь не подтверждена. GitHub-импорт плагина с `mcp.json` в рабочем пространстве относится к Desktop-only пути даже для HTTPS MCP. Для cloud-импорта используется зарегистрированное приложение и отдельная привязка с реальным app ID. Локальная установка Codex — другой host и не устанавливает плагин в ChatGPT Work.

## Обновление

Для опубликованного плагина следуй штатному обновлению ChatGPT. Для личной сборки обнови навыки и привязку к точному URL нового официального пакета. Новый URL меняет OAuth resource: выполни штатное переподключение или создай отдельное подключение, если этого требует ChatGPT. Не переноси старые access/refresh tokens вручную. Сохраняй прежнее работающее подключение до проверки нового и не меняй остальные подключения. Затем начни новый чат и повтори проверки. Не меняй только номера версии или digest вручную.

`release.json` содержит состав и digest пакета. В `sha256-normalized-payload-map.1` последний digest-сегмент cloud URL заменяется 64 нулями перед хешированием MCP JSON; остальные значения и файлы сохраняются. Это публичная идентификация исходного пакета, а не credential или доказательство загрузки навыков. Полный прогон ChatGPT Work с пользовательским OAuth и всеми навыками пока не подтверждён.

Официальные справки: [формат и OAuth](https://developers.openai.com/plugins/build/plugins), [публикация](https://developers.openai.com/plugins/deploy/submission), [личные плагины](https://learn.chatgpt.com/docs/build-plugins), [workspace imports](https://learn.chatgpt.com/docs/enterprise/plugin-management).
