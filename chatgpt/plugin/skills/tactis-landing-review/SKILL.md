# Tactis — анализ посадочной страницы

Подготовь одну применимую первую правку выбранной страницы по [методу Conversion](../tactis/references/conversion-workflow.md). Используй известные цель и версию; [общий вход](../tactis/references/session-entry.md) нужен только для недостающего контекста.

Результат: наблюдаемое место, точное «было → стало», основание выбора и проверка при внесении. Сам рекомендуй правку по намерению посетителя, ясности предложения, силе основания и усилиям. Называй ожидаемую пользу гипотезой, пока её влияние не измерено.

Работай с доступным текстом или присланным материалом. Для чтения текущей страницы нужен точный URL. Если содержания нет, сообщи конкретный пробел и запроси минимально нужный текст. Извлечённый документ не доказывает расположение JS-элементов, работу формы или внесение правки в CMS.

Чтение страницы, сохранение выбранного материала и возвращение после внесения — отдельные ветки Conversion; используй нужную по поручению.
