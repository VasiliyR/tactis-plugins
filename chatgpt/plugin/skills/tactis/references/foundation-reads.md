# Choose the evidence for this question

Reuse known project/account, source locators and already read evidence. This is a routing table, not an account-wide checklist. Open one matching procedure only when its source is needed; skill switching does not require reading it again.

| Needed evidence | Procedure |
| --- | --- |
| Current/today metrics, finite refresh or targeted keyword/geo/demographic slice | [Current metrics](source-current-metrics.md); this can admit collection, so an explicit no-collection request uses retained evidence instead |
| Existing Daygrain metrics, weekly chart or coverage gap | [Retained evidence](source-history.md) |
| Exact saved Analysis/Dossier/Configuration/native proof | [Proof readers](source-proof.md) |
| Missing annual archive | [Historical acquisition](source-inventory.md#longer-historical-acquisition), only when new collection is permitted |
| Full configuration inventory, a missing Analysis or Dossier family | [Inventory and analysis](source-inventory.md) |
| Offer, price, landing text or supporting claim span | [Landing evidence](source-landing.md) |
| Raw Metrika visit/goal export or whole-counter reconciliation | [Metrika Logs](source-metrika-logs.md) |
| Joined advertising, Metrika and CRM | [Marketing data matrix](marketing-data-matrix.md) over exact retained inputs |
| Saved report, material or earlier Work | [Saved results](saved-results.md), without a fresh full brief or source capture |

Keep source scope, period/timezone, event/attribution, units/VAT, as-of and coverage with every conclusion. Missing/null is unknown, not zero; technical events are not qualified leads or payments. A publication, wrapper or successful job does not establish a provider effect or business improvement. Actual schemas and current owner rights govern each call.
