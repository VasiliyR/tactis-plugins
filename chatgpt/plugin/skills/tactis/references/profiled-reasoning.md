# Evidence to a useful marketing decision

Use one recipe below when its deeper reasoning changes the user's next result. [Target-native procedures](target-procedures.md) supplies current action paths; [shared invariants](invariants.md) governs source meaning and authority. The external host reasons and authors. Tactis runs no second model, positional inference engine or semantic judge.

For negative conflicts, the managed-keyword exception matters: a negative phrase whose words are all contained in that managed keyword can be ignored by Direct for that keyword. That alone does not prove a conflict; a different landing-offer intent is evaluated separately. Do not erase `!`, `+`, quotes or brackets to manufacture either safety or contradiction. Every verdict needs its own exact collision/absence/uncertainty grounds, not one generic offer copied across all phrases. Replacement actions still need the actual complete before-set and provider readback.

The ten `.jinja` files are retained **historical source/provenance** for these algorithms. Their placeholders, local positions, mandatory numeric scales and legacy output examples are not current wire contracts or user intake. Do not run them as a hidden reasoning pipeline, submit their positional JSON to MCP, fabricate a missing value or reuse old server-call evidence as host proof. Read an individual source only if it adds needed detail; current tool schemas and typed evidence remain the operational contract. A historical mention of a candidate family does not establish that this release exposes it.

Save the exact useful material/decision and original grounds through [continuation](durable-continuation.md). Reusing an unchanged accepted semantic conclusion avoids another classification; changed scope, rule expiry, evidence or applicability requires an addressed review. An old conclusion stays historical and supplies neither current write authority nor a predicted business gain.
