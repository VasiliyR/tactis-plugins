# Tactis — от запроса к полезному результату

Start with the user's requested result and existing choices. For «найди отчёт» or «продолжи» recover that saved work; for a concrete marketing task enter its matching procedure. Ask only for missing information that changes the result or next action. Supplied facts can support an immediate attributed answer without a server connection or full business interview.

When connected data or durable saving is needed, read [session entry](references/session-entry.md) once for the selected project/account. Reuse that context across skills. Ordinary work starts with the task, not a plugin version check, installation procedure or list of all tools. Obtain a missing task command through the host's supported tool search/discovery; compatibility and setup are conditional branches of session entry, not new marketing steps.

## Find, continue or choose work

- **Find a private report or material:** use [the saved-result entry](references/session-entry.md), read the selected original and answer the question. A public link or Direct connection is not required.
- **Continue a saved decision:** recover the relevant full head and the exact material needed through [durable continuation](references/durable-continuation.md), retain its selected source/version and do the requested next step. Reconstruct from saved results, not chat history or a new onboarding.
- **Explain capabilities or choose an open first task:** read [useful tasks](references/capabilities-guide.md). A general explanation needs no OAuth or project selection. Offer up to three relevant results when the task is open; a chosen result needs no catalogue detour. This guide also preserves all product routes and cross-product transitions for mixed work.

## Enter the requested marketing task

Read only the matching skill or procedure when its substantive result is needed. These share the same client context and saved Work; switching does not invoke another agent or restart intake.

For files/sharing, imports/media plans, CRM/offline conversions, monitoring, audiences or feeds/Webmaster, enter the matching [platform scenario](references/platform-workflow.md). For a growth priority across tasks, use [Growth](references/growth-workflow.md); its first useful material need not wait for every source. The [product route map](references/capabilities-guide.md) preserves Ads, Automation, Audience, Creative, Reports, Profit, Experiments, Conversion, SEO, Sales, Lifecycle and Growth handoffs. Read the next procedure only when reaching its actual stage.

Use [project goals](references/project-goals.md) when goals, numerical targets, source meanings or a material priority/budget decision are involved. Read relevant brief attention and [project signals](references/project-signals.md) for the decision being made; a signal does not require a full audit or authorize an external action. Source facts and coverage use [foundation reads](references/foundation-reads.md); a provider change uses the exact current schema and [current actions](references/current-actions.md).

## Save the useful result and its next step

Present ordinary analysis in chat; create a report, export, publication or schedule when requested. Automatically save a substantive new finding, complete chosen material, decision or next check through [shared invariants](references/invariants.md) and [durable continuation](references/durable-continuation.md); its committed receipt confirms saving. Routine successful saving stays silent; explain an unresolved save. A cosmetic rerender or simple acknowledgement needs no duplicate Work. Intermediate task work stays pending.

Carry the exact project/account, source and Work locators, complete selected material, actual state, limitations and next check across procedures. Preserve unrelated active work and explicit project-only scope. A direct user business fact/correction is the applicable choice for those exact context values; inferred assumptions stay uncertain. Current business generation and source meaning still apply. Supported provider actions follow **freeze → applicable choice → execute → readback**; a saved plan, recommendation or host permission does not supply the user's money/access choice or prove an external effect.

Installation/update diagnostics and existing due-task delivery are used only for their concrete event through [session entry](references/session-entry.md). The external agent performs the marketing reasoning; server jobs do not run a hidden marketing model. Another host authenticates independently and restores the same authorized saved artifacts.
