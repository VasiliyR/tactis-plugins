# Tactis Ads

This extension provides the canonical marketing skills and `tactis_ads` MCP. Use the matching `skills/<skill>/SKILL.md`; for mixed work or continuation start with `skills/tactis/SKILL.md`. Reuse known project context and applicable choices.

When connected work cannot discover Tactis tools or startup/authentication fails, read [MCP connection recovery](skills/tactis/references/mcp-connection.md). For a requested install/update or a proven package incompatibility, use [native extensions](skills/tactis/references/plugin-updates.md#native-extensions), preserving the Qwen package identity and existing connection. These references contain the host-specific commands and checks.

Installation and source connection do not authorize advertising changes, spending or publication.
