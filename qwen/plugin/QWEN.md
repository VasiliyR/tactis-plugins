# Tactis Ads

This extension provides the canonical Tactis marketing skills and the `tactis_ads` remote MCP server.
For a marketing task, read the matching local `skills/<skill>/SKILL.md` and its referenced resources. For mixed work or continuation, start with `skills/tactis/SKILL.md`. The complete inventory is in `methodology.json`.

Use the server's current tool schemas. Project access is selected separately through browser OAuth. Installation does not authorize advertising changes, spending, publishing or changes to access.

When installing or updating, use Qwen Code's native extension manager with the verified Qwen archive or local `qwen/plugin` directory. Do not install the repository's Claude marketplace entry as the Qwen package: conversion can select a different host identity. Preserve other extensions, settings and OAuth credentials. Refresh the host context, then check `get_plugin_update_status`, `list_projects` and a read-only `get_project_brief` for the selected accessible project. Method compatibility, package freshness and live access are separate checks.
