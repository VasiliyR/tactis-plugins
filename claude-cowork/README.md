# Tactis Ads для Claude Cowork

Восемь навыков Tactis помогают готовить рекламные тексты, разбирать рекламу и измерение, проверять страницы и сохранять результаты работы с бизнесом. Навыки находятся в `skills/`; один remote MCP `tactis_ads` подключает данные через OAuth.

## Установка

1. Скачай ZIP `tactis-ads-claude-cowork-v<версия>.zip` из [официального выпуска Tactis](https://github.com/VasiliyR/tactis-plugins/releases). Сверь версию с `release.json` внутри пакета. Этот архив содержит один плагин: `.claude-plugin/plugin.json` находится непосредственно в его корне.
2. В Claude Desktop открой Cowork → Customize → Plugins и выбери Upload plugin в меню добавления. Выбери ZIP. Названия промежуточных пунктов могут зависеть от версии приложения и доступа организации. Если Upload plugin недоступен, нужен разрешённый администратором способ установки.
3. Открой Customize → Plugins → Tactis Ads → Connectors. При Not added нажми Add (при ограничении обратись к owner/admin); при Not connected — Connect и выполни вход в Tactis через браузер, подтвердив аккаунт, проекты и права. При Connected и отсутствующих инструментах сначала проверь фактическую ошибку/активацию, не повторяй OAuth без причины. Если Cowork предлагает отдельно добавить custom connector, используй точный URL из `.mcp.json`, включая весь путь после `/mcp/cloud/`. Навыки могут загрузиться без подключённого коннектора; это отдельные состояния. Подробности — [восстановление MCP](skills/tactis/references/mcp-connection.md).
4. Открой новый чат Cowork, выбери Tactis Ads и попроси показать доступные навыки, вызвать `get_plugin_update_status`, `list_projects` и затем `get_project_brief` для выбранного проекта. Проверь результаты и версии; наличие URL не доказывает загрузку навыков.

Пакет для Cowork имеет host `claude-cowork`. Корневой Git marketplace Tactis продолжает устанавливать отдельный пакет Claude Code. Не подменяй им Cowork ZIP и не меняй host в `release.json` или URL вручную.

## Обновление и проверка

Обнови существующий Tactis Ads через поддержанный менеджер Cowork новым ZIP из официального выпуска. Обнови подключение на точный URL нового пакета, если программа не делает этого сама. Новый URL меняет OAuth resource: выполни штатное переподключение или создай отдельное подключение, если этого требует Cowork. Не переноси старые access/refresh tokens вручную. Сохраняй прежнее работающее подключение до проверки нового и не меняй остальные плагины. После обновления начни новый чат и повтори три проверки. Если программа требует удалить существующую установку или отключить организационные ограничения, сначала выясни конкретный штатный путь обновления.

`release.json` содержит состав и digest пакета. В `sha256-normalized-payload-map.1` у MCP JSON нормализуется только последний digest-сегмент cloud URL: вместо него используется 64 нуля; остальные значения и файлы участвуют в проверке. Пакет не содержит токенов, секретов, фиксированных HTTP-заголовков или установочных скриптов. URL передаёт публичную версию пакета; доступ даёт отдельная OAuth-авторизация.

Это проверенная сборка пакета и серверного контракта. Полный прогон установленного Cowork с пользовательским OAuth пока не подтверждён. Права на изменения рекламы определяются отдельным поручением и серверными проверками.

Официальные справки: [плагины Cowork](https://claude.com/docs/plugins/overview), [сборка плагина](https://claude.com/docs/plugins/build), [формат плагина Claude](https://code.claude.com/docs/en/plugins-reference).
