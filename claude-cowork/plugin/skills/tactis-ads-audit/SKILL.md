# Tactis — аудит и улучшение рекламы

Объясни, что изменилось, какое объяснение поддерживают данные и что сделать первым. Используй известные проект, цель, событие и ограничения; [общий вход](../tactis/references/session-entry.md) нужен только для недостающего контекста.

Выбери одну процедуру: [performance diagnosis](../tactis/references/performance-diagnosis.md) для ухудшения, [symptom route](../tactis/references/optimization-recipes.md) для отдельного вопроса, [marketing review](../tactis/references/marketing-review.md) для полного или периодного обзора. Перед новой гипотезой используй относящееся к ней [прежнее обучение](../tactis/references/prior-learning.md).

Сравни совместимые периоды и найди главный известный отрицательный вклад. Сохраняй смысл события, валюту/НДС, атрибуцию и покрытие. Расходы, технические события, квалифицированные заявки и продажи различаются; неизвестное не становится нулём. Читай только данные, которые могут изменить решение, через подходящий [источник](../tactis/references/foundation-reads.md). Для связи нескольких источников используй [матрицу](../tactis/references/marketing-data-matrix.md).

Покажи сравнение и до трёх приоритетов: **объект → основание → вывод или unknown → конкретная правка/проверка → условие возврата**. Подготовь полезный материал для первого приоритета. Отдели факт от гипотезы и альтернативного объяснения; низкий CTR или рост CPA сами по себе не доказывают причину. Обоснованное сохранение текущих настроек тоже может быть результатом.

[Изменения рекламы](../tactis/references/current-actions.md) выполняются только в рамках поручения, с точным планом, применимым выбором пользователя, текущими правами и provider readback. При неполных данных закончи доступную часть и назови конкретный недостающий источник или проверку.

Для нужного графика используй [визуальный анализ](../tactis-visual-analysis/SKILL.md), для запрошенного документа — [отчёт](../tactis-client-report/SKILL.md). Запрошенное сохранение или выбранный вывод для продолжения использует [этап сохранения](../tactis/references/durable-continuation.md#save-the-result-and-next-step).
