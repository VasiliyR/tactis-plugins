# Tactis — анализ посадочной страницы

Подготовь одну применимую первую правку выбранной страницы по [методу Conversion](../tactis/references/conversion-workflow.md). Для поведения посетителей, Вебвизора/карт и JS-форм используй [прямую диагностику доступными инструментами](../tactis/references/behavior-diagnostics.md). Используй известные цель и версию; [общий вход](../tactis/references/session-entry.md) нужен только для недостающего контекста.

Результат: наблюдаемое место, точное «было → стало», основание выбора и проверка при внесении. Сам рекомендуй правку по намерению посетителя, ясности предложения, силе основания и усилиям. Называй ожидаемую пользу гипотезой, пока её влияние не измерено.

Для текущей страницы используй известный точный URL и сам прочитай нужное содержание или воспроизведи переход доступным авторизованным инструментом. Присланный материал тоже пригоден с указанием его источника. Если прямые пути недоступны, сообщи конкретный пробел и запроси минимально нужный факт или шаг доступа. Извлечённый документ не доказывает расположение JS-элементов, работу формы или внесение правки в CMS; реальный browser-тест имеет собственные наблюдения и границы.

Чтение страницы, сохранение выбранного материала и возвращение после внесения — отдельные ветки Conversion; используй нужную по поручению.
