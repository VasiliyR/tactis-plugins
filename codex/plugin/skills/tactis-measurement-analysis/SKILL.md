# Tactis — аналитика и проверка измерения

Ответь на конкретный вопрос о показателях или достоверности измерения. Используй известные проект, событие и период; [общий вход](../tactis/references/session-entry.md) нужен лишь для недостающего контекста. Бизнес-цель нужна для оценки бизнес-успеха, а доступные числа можно объяснить уже сейчас.

Выбери нужный путь:

- [Текущие метрики](../tactis/references/source-current-metrics.md) — сегодня, свежий статус, получение отсутствующих чисел и продолжение pending-запроса.
- [Сохранённые данные](../tactis/references/source-history.md) — история, сопоставимые периоды и покрытие.
- [Матрица](../tactis/references/marketing-data-matrix.md) — совместный разбор рекламы, Метрики и CRM.
- [Logs по дням недели и часам](../tactis/references/source-metrika-logs.md) — распределение визитов и достижений выбранной цели по времени начала визита с явными timezone, периодом и неизвестным покрытием.
- [Поведение и JS-формы](../tactis/references/behavior-diagnostics.md) — прямое получение доступных наблюдений через авторизованный browser/connector и проверка перехода средствами runtime, когда native-агрегаты не отвечают на вопрос о Вебвизоре, картах или форме.
- [Measurement checklist](../tactis/references/onboarding.md#measurement-checklist) — полная проверка заявленного измерения.

Определи, что означает выбранное событие и какую связь с бизнес-результатом подтверждают данные. Клик по телефону, начало формы, квалифицированная заявка и оплата различаются. Выбирай цель по фактической привязке и определению, а не по её месту в списке. Нужную настройку или точное определение читай только при отсутствии этих фактов.

Если Директ уже подключён, а нужный срез Метрики ещё не выбран, используй [действующий Яндекс-доступ](../tactis/references/connector-setup.md#use-existing-yandex-access): сам найди счётчик/определение события и подготовь аналитическую привязку без нового входа и поиска ID пользователем. Уже пригодные привязки и прочитанные определения переиспользуй. Подготовка данных входит в исходную задачу.

Если нужного определения ещё нет, настрой его по [точному пути Метрики](references/goal-setup.md) в пределах поручения и действующего права записи. Создание определения не подтверждает установку тега, отправку события или получение заявки.

Сопоставляй окно/timezone, событие, атрибуцию, валюту/НДС, покрытие и зрелость. Считай агрегированные отношения из совместимых сумм, а не среднего CPA/CR сегментов. Пересекающиеся цели не складываются; Direct AUTO и Метрика LASTSIGN не образуют доказанный общий коэффициент. Missing, sampling/suppression, неизвестное и наблюдаемый ноль различаются; нулевой знаменатель оставляет отношение неопределённым.

Для сегодняшнего дня сохраняй предварительность, время получения и ограничения обработки. Сравнение неполного дня с полными сутками не является сравнением равных окон. Пригодная свежесть ответа не доказывает, что провайдер уже обработал все события. Настройки/статус показов читай отдельно, только когда они нужны для вывода.

Дай числа с периодом и существенным ограничением либо конкретную проверку, которая позволит использовать событие для решения. Для полного measurement-аудита покажи **проверка → passed / needs_attention / unknown → основание → последствие**. Чтение цели не доказывает работу тега или отправку формы.

Для вопроса о странице/устройстве используй соответствующий этап [Conversion](../tactis/references/conversion-workflow.md), о заявках/продажах — [Sales](../tactis/references/sales-workflow.md), об экономике — [Profit](../tactis/references/profit-workflow.md). Для причины ухудшения продолжи [ads audit](../tactis-ads-audit/SKILL.md) с уже прочитанными фактами; для представления — [visual analysis](../tactis-visual-analysis/SKILL.md).

При неполных данных покажи независимо известные показатели и сам получи недостающий срез доступным инструментом. Если нужен новый доступ, подготовь точный переход [настройки и продолжения](../tactis/references/connector-setup.md); если отсутствует сама возможность, используй пригодный поддержанный альтернативный источник. Назови оставшийся существенный пробел, когда его действительно не удалось устранить. Числа пользователя допускают атрибутированный предварительный расчёт. Запрошенное сохранение или выбранный вывод для продолжения использует [этап сохранения](../tactis/references/durable-continuation.md#save-the-result-and-next-step); подробности записи нужны при этой операции.
